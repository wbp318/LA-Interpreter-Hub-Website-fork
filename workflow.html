Consecutive mode

How a turn-taking exchange flows

Text version of this chart
  1. The provider speaks a short segment.
  2. The interpreter renders it for the other speaker.
  3. The speaker responds.
  4. The interpreter renders the response for the provider.
  5. If anything is unclear, the interpreter clarifies openly.
